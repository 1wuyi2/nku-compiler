# 南开大学编译原理课程实验

本仓库用于存放南开大学编译原理课程的预备作业及后续实验代码、实验结果和报告材料。

## 目录结构

- `prework1/`：预备作业 1，主要包括编译流程研究、LLVM IR 编程和 RISC-V 汇编编程
- 后续 `lab*` 目录：用于存放后续编译原理实验

## 预备作业 1

### Part 1：编译器工作流程研究

以阶乘程序为例，使用 GCC/Clang 观察完整的语言处理过程，包括：

C 源程序  
→ 预处理  
→ Token  
→ AST  
→ LLVM IR  
→ x86-64 汇编  
→ 可重定位目标文件  
→ 链接生成可执行程序

此外，对 GCC 在 `-O0` 和 `-O2` 优化等级下生成的汇编代码进行了比较，观察寄存器使用、内存访问和循环优化等差异。

### Part 2：SysY、LLVM IR 与 RISC-V

设计一个覆盖多种语言特性的 SysY 示例程序，并分别完成：

- 等价 LLVM IR 实现
- 等价 RISC-V 汇编实现
- 链接 SysY 运行时库
- 使用统一测试用例验证不同实现的运行结果一致性

## 小组分工

Part 2 中：

- 一名成员主要负责 LLVM IR 实现及 x86 平台运行验证
- 一名成员主要负责 RISC-V 汇编实现及 QEMU 运行验证
- 两人共同完成 SysY 示例程序设计、测试用例设计、结果一致性检查和实验报告整理
